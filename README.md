# Cseelye Tap

## How do I install these formulae?

`brew install cseelye/tap/<formula>`

Or `brew tap cseelye/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "cseelye/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
